# SFTP Project Manager

Portable-приложение: Go + Wails v2 + Vue 3 + TypeScript. Поддерживает несколько проектов и подключений. У каждого сервера есть корень просмотра, а маппинги связывают локальные папки с каталогами относительно этого корня; удалённое дерево можно просматривать вне маппингов, передача идёт по выбранному маппингу. Есть локальное/удалённое дерево, множественный выбор и рекурсивная передача папок с общим предпросмотром и подтверждением перезаписи. Подробнее: [корень сервера и маппинги](docs/root-deployment.md).

Рабочее окно устроено по модели PhpStorm: полный локальный проект слева, сервер справа. При первом запуске создайте проект только с локальной папкой; серверы добавляются позже в отдельном окне настроек. Первый сервер становится сервером по умолчанию, выбор можно изменить. Сценарий: [ide-workspace.md](docs/ide-workspace.md).

Локальную папку проекта можно указать вручную или выбрать кнопкой «Обзор…» через стандартный диалог Windows. Выбор заполняет форму; проект сохраняется отдельной кнопкой. Отмена диалога сохраняет прежний путь.

В режиме SSH-алиаса кнопка «Прочитать SSH-алиасы» читает пользовательский либо указанный конфиг и Include без выполнения команд. Выбор имени заполняет черновик. Отдельная «Проверить эффективные настройки» использует `ssh -G` после подтверждения доверия: `Match exec` при такой оценке может выполнять команды. Проверка ограничена 15 секундами; под Windows отмена завершает дерево её процессов. Поддержка и ограничения: [ssh-discovery.md](docs/ssh-discovery.md).

## Разработка

На машине разработчика нужны Go 1.26.5, Node.js 24.13.0, npm и WebView2 Runtime. Зафиксированы Wails v2.16.0 и версии frontend в `package.json`/`package-lock.json`; Go-зависимости — в `go.mod`/`go.sum`.

```powershell
cd frontend
npm ci
npm run build
cd ..
go test ./...
go vet ./...
go run github.com/wailsapp/wails/v2/cmd/wails@v2.16.0 dev
```

В режиме разработки `data` создаётся рядом с exe, который запускает Wails. Для проверки поведения поставки используйте release-сборку.

При установленном GNU Make из корня проекта доступны команды:

| Команда | Действие |
| --- | --- |
| `make vet` | Проверка Go-кода через `go vet ./...` |
| `make test` | Все Go-тесты без использования кеша результатов |
| `make frontend-test` | Тесты состояния деревьев через Node 22.18+ / 24+ |
| `make verify-ui` | Сборка frontend и браузерная проверка с тестовым мостом в headless Edge; PNG в `dist/ui-review` |
| `make check` или `make` | Проверка Go-кода, Go-тесты и frontend-тесты |
| `make build` | Windows x64 exe вместе с frontend в `build/bin/sftp-project-manager.exe` |
| `make dev` | Полное приложение Wails с Go backend и горячим обновлением frontend |
| `make frontend-dev` | Только Vite-сервер frontend через `npm run dev`, без Go backend |

Для разработки с сохранением настроек, выбором папок и SFTP используйте `make dev` и открывшееся окно приложения. В отдельном браузере через `make frontend-dev` мост Go/Wails недоступен, поэтому появляется сообщение «Откройте приложение через Wails».

Перед первым отдельным запуском frontend установите зависимости: `npm --prefix frontend ci`. Адрес локального сервера выводится в терминале; остановка — `Ctrl+C`. `make build` собирает exe; упаковка ZIP описана ниже.

## Сборка Windows x64

Из PowerShell в корне проекта:

```powershell
.\scripts\build.ps1
```

Результат: `build/bin/sftp-project-manager.exe` и `dist/sftp-project-manager-windows-amd64.zip`. Wails собирает frontend и встраивает его в exe. Скрипт использует `-webview2 error`: приложение не скачивает и не устанавливает runtime автоматически.

Если политика PowerShell запрещает `.ps1`, выполните команды напрямую, без изменения политики:

```powershell
go run github.com/wailsapp/wails/v2/cmd/wails@v2.16.0 build -platform windows/amd64 -webview2 error
# Упаковку выполнять только после успешной сборки.
New-Item -ItemType Directory -Force dist
Compress-Archive -LiteralPath build/bin/sftp-project-manager.exe,docs/smoke-test.md,docs/verification.md,docs/proxy-connections.md,docs/exclusions.md,docs/file-trees.md,docs/remote-navigation.md,docs/root-deployment.md,docs/password-auth.md,docs/batch-transfers.md,docs/transfer-queue.md,docs/ide-workspace.md,README.md -DestinationPath dist/sftp-project-manager-windows-amd64.zip -Force
```

## Portable-запуск

Распакуйте ZIP в доступную для записи папку и запустите exe. Go и Node.js конечному пользователю не нужны. Эта поставка использует установленный WebView2 Runtime; автономный архив с Fixed Version Runtime пока не подготовлен. Совместимость и запуск на рабочем ноутбуке требуют [ручной проверки](docs/smoke-test.md) (в архиве файл `smoke-test.md` лежит рядом с exe).

Настройки: `data/settings.json`, предыдущая валидная версия: `data/settings.json.bak`, данные браузера: `data/webview2`. Пути вычисляются относительно exe, а не рабочей папки. При ошибке доступа перенесите приложение в папку, доступную для записи. Повреждённый конфиг или неизвестная версия схемы останавливают запуск: сохраните исходный файл и восстановите резервную копию вручную. Автоматического сброса нет.

Проекты сохраняются в `projects` схемы 3. У сервера отдельный `rootPath`, у маппинга — `localPath` и относительный `deploymentPath`. Схемы 1 и 2 мигрируют в памяти без изменения назначений; первая запись сохраняет исходник в `settings.json.v1.bak` или `settings.json.v2.bak`. Ключи и пароли не копируются и не хранятся. Модель и правила описаны в [projects.md](docs/projects.md).

## Подключение и передача

1. Создайте проект: название и существующая локальная папка. Он сохраняется в JSON без обязательного сервера; слева автоматически появится дерево проекта.
2. В правой области откройте настройки серверов, добавьте именованное подключение: SSH-алиас из `.ssh/config` либо host/user/port и необязательный абсолютный путь ключа (иначе SSH-agent). Укажите корень просмотра сервера, например `/var/www/html`. Отдельно задайте непересекающиеся маппинги: локальная папка проекта и путь deployment от серверного корня (`.` означает сам корень). При необходимости добавьте серверы и выберите default. Ручной режим не читает пользовательский SSH-конфиг; алиас использует пользовательский или явно выбранный файл.
3. Сохраните настройки. Выберите сервер в заголовке правой панели и явно подключитесь/обновите дерево или раскройте его корень. Слева остаётся полный локальный проект. Вложенные папки загружаются при раскрытии, повторное раскрытие использует кеш. «Обновить» у папки перечитывает её и сбрасывает вложенные ветки. При старте автоматического SSH нет. Поведение: [file-trees.md](docs/file-trees.md).
4. Выделите файлы/папки кликом, Ctrl или Shift. Выберите передачу через ПКМ либо быструю кнопку сервера по умолчанию. Папки включают нераскрытые вложенные ветки. Проверьте общий план: сервер, направление, пути, объём, создания папок и пропуски. Существующие файлы пропускаются, пока явно не разрешена перезапись. Включённые `.env`/`.env.*` требуют отдельного подтверждения. Нажмите «Добавить в очередь»; недостающие папки создаются по плану внутри маппинга.
5. Для остановки нажмите «Отменить текущую операцию». Проверьте результаты каждого элемента, затем обновите дерево назначения. Передача может завершиться частично; готовые файлы/папки не откатываются. Для повтора заново выберите нужные файлы и проверьте новый предпросмотр: скрытого повтора нет. Контракт: [batch-transfers.md](docs/batch-transfers.md).

По умолчанию `BatchMode=yes` использует ключ или агент. Для входа по паролю выберите «Пароль» в настройках сервера: приложение запросит его при подключении, без сохранения в конфиге. Подробности: [password-auth.md](docs/password-auth.md). Зашифрованный ключ пока должен быть доступен агенту; passphrase/MFA требуют отдельной реализации и проверки. На Windows приватный ключ должен иметь права, принимаемые OpenSSH; приложение не меняет его ACL.

Проверка ключа сервера обязательна (`StrictHostKeyChecking=yes`). Неизвестный или изменённый ключ останавливает подключение. Для нового сервера сначала получите ожидаемый отпечаток по доверенному каналу и подтвердите его обычным OpenSSH вне приложения с тем же конфигом и known_hosts. Не принимайте изменённый ключ без проверки. Диалог добавления ключа в самом приложении пока отсутствует. Можно явно выбрать другой абсолютный путь known_hosts; файл не переписывается приложением.

ProxyJump (включая цепочку узлов) и ProxyCommand поддерживаются в режиме SSH-алиаса из исходного доверенного конфига. OpenSSH может выполнять `Match exec` и команды прокси. Под Windows отмена и закрытие приложения завершают созданное дерево процессов через Job Object. Для jump-узлов задайте в конфиге `BatchMode yes`, `StrictHostKeyChecking yes`, проверенный known_hosts, `ControlMaster no` и `ControlPath none`: параметры конечного сервера на них не переносятся. Пример и ограничения: [proxy-connections.md](docs/proxy-connections.md).

В проверенном Windows OpenSSH 9.5 ProxyJump некорректно передаёт путь альтернативного конфига с пробелами. Используйте для такого подключения путь конфига без пробелов; ProxyCommand с явно заключённым в кавычки путём проверен отдельно. В portable ZIP инструкция `proxy-connections.md` лежит рядом с exe.

Удалённая навигация лениво открывает отдельную SFTP-сессию и повторно использует её для чтения папок и обновления дерева. Сессия завершается после 10 минут простоя; чтение ограничено 30 секундами, а отмена или таймаут закрывает её. Смена проекта, сервера или конфигурации подключения, а также явное отключение завершают сессию. UI показывает её состояние и позволяет отключить или переподключить сервер. Пакетные передачи используют собственные сессии и блокируют навигацию на время работы; одновременно выполняется одна удалённая операция. Общий предпросмотр ограничен 2 минутами, выполнение пакета — 30 минутами (старый API одиночной передачи — 5 минутами). Предпросмотр хранит снимок параметров профиля и одноразовый токен: последующее изменение профиля не меняет подготовленное назначение. Изменение исключений аннулирует токен. Содержимое внешнего SSH-конфига при этом не замораживается. Подробнее: [навигация по удалённым папкам](docs/remote-navigation.md).

Передача пишет во временный файл в каталоге назначения и заменяет цель после успешной копии. Удалённая перезапись требует `posix-rename@openssh.com`; удаления оригинала как обходного решения нет. Проверяются тип, размер, mtime и режим существующей цели повторно, а пакетный план проверяет изменения после предпросмотра. Симлинки/junctions не передаются; недопустимые Windows-имена и коллизии регистра отклоняются. Пакеты можно ставить в FIFO-очередь с прогрессом по байтам и элементам, паузой, отменой и повтором выбранных ошибок. Очередь хранится в памяти до закрытия приложения; подробности — в [описании очереди](docs/transfer-queue.md).

В настройках каждого подключения есть исключения — по одному правилу на строку, пути от корня проекта, синтаксис `*`, `?`, `**`. Они действуют на upload и download: элементы видны с пометкой «исключён», открытие и передача блокируются. Новые подключения предлагают исключения `.git`, `node_modules` и `.env`; старые правила не меняются. После изменения правил сохраните проект и заново подготовьте передачу. Примеры и ограничения: [exclusions.md](docs/exclusions.md).

Метаданные не доказывают равенство содержимого и не дают полной защиты от конкурентной замены путей. ACL/владелец цели не сохраняются; для перезаписи сохраняются доступные permission bits. После обрыва SSH удалённый временный файл может остаться — ошибка очистки содержит его путь. Приложение не переподключается ради скрытой очистки или повтора. Подробности проверок и ограничений: [verification.md](docs/verification.md).

Для диагностики без GUI (также создаёт начальные настройки):

```powershell
& .\build\bin\sftp-project-manager.exe --diagnostics
```

## Структура

- `internal/config`: JSON, версия схемы, временная запись и резервная копия.
- `internal/application`: действия приложения и диагностика, без зависимости от Wails.
- `internal/mapping`: границы путей и Windows-имена.
- `internal/transport`: системный OpenSSH и SFTP поверх stdin/stdout.
- `internal/transfer`: безопасная передача одного файла через временный файл.
- `app.go`: ограниченный мост для Vue.
- `main.go`: запуск окна и portable-пути.
- `frontend/src`: интерфейс Vue/TypeScript.
- [План](sftp-project-manager-plan.md), [краткий контекст](docs/agent-context.md), [проверки](docs/verification.md).

Запись сначала выполняется во временный файл в той же папке с `Sync`, затем через `os.Rename`. Атомарность замены и устойчивость к отключению питания не гарантируются на всех файловых системах. Одновременный запуск нескольких экземпляров пока не поддержан.
