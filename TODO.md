# Отложенные доработки

- [ ] После полировки основных функций перенести настройки проекта в скрытую папку внутри его локального корня, по аналогии с `.idea`.
  - Перед реализацией выбрать имя папки и состав настроек: подключения, корни серверов, маппинги и исключения.
  - Разделить переносимые настройки проекта и персональные настройки пользователя; решить, какие файлы можно хранить в Git, а какие следует игнорировать.
  - Общие настройки приложения и список недавних проектов оставить вне репозитория. Пароли, приватные ключи и другие секреты не сохранять в проекте.
  - Предусмотреть миграцию текущего `data/settings.json` с резервной копией, а также поведение для папок без права записи и нескольких пользователей.
  - Исключить служебную папку приложения из передачи на сервер и поиска по файлам.
