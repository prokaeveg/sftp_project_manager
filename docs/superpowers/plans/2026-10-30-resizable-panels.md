# Панели и цвет проекта

**Цель:** независимый ресайз боковых секций, скругления по согласованному дизайну и цвет верхней панели из JSON проекта.

**Архитектура:** компонент ResizableWorkspace оборачивает три существующих секции через слоты. Чистый модуль ограничивает ширины и читает настройки; компонент управляет pointer capture и ResizeObserver. Project получает необязательное поле color; NormalizeProject задаёт безопасный HEX по умолчанию.
