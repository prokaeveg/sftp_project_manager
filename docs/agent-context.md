Обновлено: 7 октября 2026 года. Обновлять при существенных изменениях; хранить текущее состояние, а не историю переписки.

## Задача и ограничения

Разработка portable SFTP-менеджера по [основному плану](../sftp-project-manager-plan.md). Начать с этапа 0 и вертикального среза; ядро Go отделить от UI. Полный MVP пока не реализован.

Пользователь просит не использовать Superpowers. Дополнительные Markdown-файлы разрешены для экономии контекста; 6 октября разрешены субагенты на более дешёвых моделях. Не хранить секреты. Не считать проверку на машине разработки проверкой рабочего ноутбука.

## Текущее состояние

- Реализована основа этапа 0: Vue/Wails-окно, диагностика SSH/WebView2, сохранение названия для проверки JSON и portable-пути относительно exe.
- В репозитории есть `go.mod`: модуль `awesomeProject`, директива `go 1.26`.
- До начала работы уже имелось изменение `.gitignore`; не перезаписывать его без учёта пользовательских изменений.
- На момент первоначального поиска `AGENTS.md` в проекте не найден.
- Реализован первый вертикальный срез: один профиль и корневой маппинг, алиас/manual connection, локальные/удалённые списки, предпросмотр с одноразовым токеном и снимком профиля, upload/download одного файла, разрешение перезаписи, отмена и завершение процесса.
- Встроенного доверия новому host key нет: OpenSSH строго проверяет known_hosts, новый отпечаток подтверждается пользователем вне приложения. ProxyJump/ProxyCommand, управление деревом процессов, исключения и два дерева файлов реализованы. Множественный выбор и рекурсивная передача используют [пакетный план](batch-transfers.md). Реализована [очередь](transfer-queue.md) с прогрессом, паузой, отменой и ручным повтором. Постоянный журнал отложен пользователем. Авторизация по паролю реализована через SSH_ASKPASS и диалог без сохранения секрета (password-auth.md); passphrase/MFA ещё не реализованы.
- Обсуждён импорт проектов PhpStorm: планом добавлен post-MVP импорт из выбранной родительской папки с поиском `.idea`, предварительным просмотром и переносом поддерживаемых SSH/SFTP настроек без секретов и без автоматического подключения. Перед реализацией изучить реальные варианты XML по версиям и отличать project-level настройки от IDE-level. См. раздел «Импорт проектов PhpStorm» в основном плане.
- `internal/mapping`, `internal/transport`, `internal/transfer` дополняют сервис. Текущая схема настроек — 3 с `projects` и активными ID; схемы 1 и 2 мигрируют в памяти без записи при загрузке. У подключения есть абсолютный POSIX `rootPath`, у маппинга — проектный `localPath` и серверный относительный `deploymentPath`; `Profile.remoteRoot` вычисляется из корня и активного маппинга. Удалённое дерево показывает `rootPath`, включая unmapped-пути; передача требует ровно одного маппинга. Подробности: [root-deployment.md](root-deployment.md). `bridge.ts` содержит актуальный узкий API, сверенный с генерацией Wails.
- Структура: `internal/config` (хранилище), `internal/application` (сервис), `app.go` (мост), `main.go` (Wails), `frontend/src` (Vue/TypeScript).

## Рабочие предположения и открытые вопросы

Рабочий стек из плана: Go + Wails v2 + Vue 3 + TypeScript; русский UI; OpenSSH-процесс и SFTP через stdin/stdout; JSON в `data` рядом с exe. Это предположения, а не новые подтверждения пользователя.

Поддержка обоих ProxyJump и ProxyCommand подтверждена пользователем 6 октября и реализована. Jump-узлы требуют собственной строгой политики в доверенном конфиге; параметры конечного сервера не наследуются. Windows OpenSSH 9.5 неправильно передаёт путь `-F` с пробелами во внутреннюю команду ProxyJump; использовать путь без пробелов. Контракт и пример: [proxy-connections.md](proxy-connections.md). Ответ о Windows/архитектуре рабочего ноутбука, наличии `ssh.exe` и способе авторизации пока не получен. Сведения о машине разработки не заменяют этот ответ.

## Сохранение пароля и сервер без маппингов — 7 октября 2026

Реализовано: галочка «Сохранить пароль» в диалоге, canRemember только для OpenSSH password-вопросов, ForgetSavedPassword в настройках. internal/credentials использует generic Windows Credential Manager с локальным постоянным хранением для текущего пользователя; JSON/portable ZIP секретов не содержат. internal/application/saved_password.go оборачивает открытие сессий навигации и передач, ключ — хеш Connection + хеш текста запроса. Подстановка один раз на попытку; повторный вопрос удаляет отклонённую запись; ручной ответ сохраняется только после успешного SSH/SFTP-входа. Одинаковые параметры в проектах используют общую запись. Passphrase/MFA пока не сохраняются. Контракт: password-auth.md.

Новый сервер: rootPath `/`, mappings `[]`. Save/Load/Select допускают active connection без active mapping и Profile. navigationKey читает SSH-параметры непосредственно из выбранного подключения, поэтому навигация работает и без Profile; смена параметров закрывает старую сессию. Передача без маппинга отклоняется; первый маппинг добавляется вручную. Старые маппинги не удаляются. Проверены Go/race/vet, native Credential Manager, browser mock и Windows build; рабочая сеть/нативный UI остаются ручной проверкой.
