# Множественный выбор и рекурсивная передача

Контракт этапа 3. Для оптимизации контекста читать этот файл, затем `internal/application/batch.go` и затрагиваемые тесты/компоненты. Общую историю разработки не перечитывать.

## Сценарий

Отметить файлы/папки в одной панели и нажать загрузку выбранного на сервер или скачивание на компьютер. Рабочее окно имеет [полное локальное дерево проекта](ide-workspace.md); перед upload его пути переводятся в текущий маппинг. Выбор вне маппинга отклоняется с подсказкой. Удалённый корень `.` охватывает только текущий маппинг; локальный корень всего проекта передаётся целиком лишь при маппинге `.`. Папки обходятся рекурсивно даже без раскрытия в дереве; выбор родителя вместе с ребёнком не дублирует передачу.

Предпросмотр явно подключается к SSH и читает обе стороны, но ничего не создаёт. Показывает сервер, направление, полные пути, число обычных файлов и известный объём, существующие назначения, план создания папок и причины пропусков. Объём включает существующие файлы до выбора политики пропуска; это не размер отличающегося содержимого.

Существующие файлы по умолчанию пропускаются. Для перезаписи требуется отдельное разрешение в текущем плане; «Отменить» закрывает предпросмотр без передачи. Исключения применяются в обе стороны. Исключённые папки, ссылки/junctions и специальные файлы показываются как пропуски без обхода. Чтобы включить исключённый файл, нужно изменить правила и сохранить проект, затем построить новый план. Для включённых в план `.env` и `.env.*` нужно дополнительное явное разрешение; backend проверяет его тоже.

Создаются только запланированные отсутствующие папки внутри текущего маппинга, включая пустые папки и необходимые родители выбранных файлов. Оба корня маппинга должны существовать. Папки не заменяют файлы, файлы не заменяют папки. Недопустимые Windows-имена, коллизии регистра, небезопасные промежуточные пути и конфликты типов останавливают построение плана до записи.

## Выполнение и результаты

План фиксирует подключение, корни, исключения, список элементов и доступные метаданные источников/назначений. Это снимок, не динамический обход: появившиеся после предпросмотра файлы не добавляются. Изменение исключений аннулирует подготовленный токен. Токен одноразовый; смена выбранного профиля не перенаправляет уже подготовленный план.

Перед каждым действием повторно проверяются пути, исключения и метаданные. Изменившийся источник, новое/изменившееся назначение требуют нового предпросмотра; разрешение перезаписи не разрешает незаметно заменить другой файл. Метаданные не доказывают тождественность содержимого и не устраняют все гонки файловой системы.

Одна SSH/SFTP-сессия обслуживает предпросмотр; отдельная сессия — последовательное выполнение плана. Файлы используют прежнюю безопасную передачу через временный файл и rename; исходная цель не удаляется как обход отсутствующего POSIX rename. Папки создаются по одной с проверками родителей, без слепого `MkdirAll`.

По каждому элементу возвращается `completed`, `skipped`, `failed` или `cancelled` с подробностями. Ошибка отдельного файла не скрывает результаты других; сбой родительской папки блокирует её потомков. Отмена останавливает SSH/I/O и отмечает оставшиеся действия как отменённые. Уже переданные файлы и созданные папки сохраняются: общего отката нет. Ошибки очистки временных файлов должны оставаться в подробностях результата. После выполнения дерево назначения обновляется вручную. Повтор выполняется только через новый выбор и новый предпросмотр; скрытых повторов нет.

UI сохраняет последнее выполненное задание вместе с сервером, направлением и путями назначения даже при переключении проекта. Обновление ветки очищает выбор этой панели и закрывает предпросмотр, чтобы не оставить выбор исчезнувших элементов. Сворачивание дерева сохраняет выбор. Выбор каждой панели независим.

## API и границы

- `PreviewBatch(direction, relatives)` → `BatchPreview`: `token`, `direction`, `server`, `items`, `fileCount`, `totalBytes`.
- Элемент предпросмотра: `relativePath`, `source`, `destination`, `kind`, `size`, `exists`, `skippedReason`.
- `ExecuteBatch(token, existingPolicy, includeEnvironment)` → `BatchResult.items`: `relativePath`, `kind`, `status`, `error`. Политики: `skip` / `overwrite`.
- Старый API одиночной передачи остаётся для совместимости; UI использует пакетный API для файлов и папок.
- Лимит плана — 10 000 элементов, глубина — 64 компонента. Долгий предпросмотр/выполнение можно отменить. Настройки и другие операции UI блокируются во время работы.

Очередь нескольких заданий, процент/байтовый прогресс, постоянный журнал и выборочное повторение из таблицы результатов пока не реализованы. Ручной UI и целевой ноутбук проверяются отдельно: [smoke-test.md](smoke-test.md).
