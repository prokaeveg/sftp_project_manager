# Предпросмотр, сравнение и быстрый поиск файлов

Запрос пользователя от 8 октября 2026: центральная панель файлов между локальным и удалённым деревьями, вкладки удалённых файлов с именем сервера, сравнение с deployed version через ПКМ и поиск по Ctrl+Shift+N. План и реализация выполняются в одной сессии.

## Поведение

- Двойной клик или Enter по обычному файлу открывает вкладку предпросмотра. Локальная вкладка называется именем файла; удалённая — `имя файла [имя сервера]`. Полный путь виден в панели и подсказке вкладки. Файлы только читаются; сохранение изменений — отдельная будущая задача.
- Вкладки разных серверов независимы; переключение сервера не переименовывает открытую вкладку. Смена проекта закрывает вкладки. Обновление читает файл заново с исходного сервера.
- ПКМ по одному файлу: «Compare with deployed version on <default server>» и «Compare with…» с выбором остальных серверов, если их несколько. Для удалённой строки сначала определяется проектный путь через mapping исходного сервера; затем mapping целевого сервера. Активное подключение при сравнении не меняется.
- Модальное сравнение показывает локальный файл слева, серверный справа, номера строк и добавленные/удалённые строки. Отдельно сообщается о полном равенстве или различии файлов. Сравнение ничего не записывает.
- Ctrl+Shift+N открывает модальный поиск по имени во всём локальном проекте, включая ещё не раскрытые папки. Поиск регистронезависимый, поддерживает последовательность символов, показывает путь и открывает результат Enter/двойным кликом. Escape закрывает; стрелки выбирают результат. Исключения выбранного подключения, помеченные папки проекта и ссылки пропускаются.

## Исключение папок из поиска

ПКМ по локальной папке: `Mark directory excluded`; дерево показывает «исключена из поиска». Пометка принадлежит проекту, действует на всё поддерево и сохраняется после перезапуска, независимо от выбранного сервера. `Unmark directory excluded` возвращает папку в поиск; если исключён родитель, сначала нужно вернуть в поиск его. Содержимое можно открывать вручную: поисковые пометки применяются к обходу поиска.

При создании нового проекта включается `excludeDotDirectories`: все папки с именем, начинающимся на `.`, включая вложенные и появившиеся позднее, помечаются автоматически. Отдельный dot-файл вроде `.env` этим правилом не исключается. Снятие пометки конкретной dot-папки сохраняется в `searchIncludedDirectories`; ручные пометки — в `searchExcludedDirectories`. Старые проекты без этих необязательных полей сохраняют прежние настройки; схема JSON остаётся 3.

Вместо неявного запрета имён `.git`/`node_modules` поиск использует проектные пометки и существующие deployment-exclusions выбранного подключения. Последние по-прежнему учитываются, даже если поисковая пометка снята.

## Ограничения и безопасность

Предпросмотр читает максимум 2 МиБ плюс байт проверки лимита; поддерживает UTF-8 и UTF-16 с BOM. Бинарный файл или неизвестная кодировка отображается как недоступный для текстового просмотра. Для обрезанных файлов полноценное сравнение недоступно. HTML и код отображаются как текст.

Все пути проверяет backend: границы проекта/rootPath, существующие ссылки/junctions, обычный тип файла и exclusions. Для remote используются существующая авторизация, сериализация SSH-операций и отмена; активный сервер переиспользует навигационную сессию. Отдельный сервер сравнения читает через отдельную сессию без смены active ID. Контент не сохраняется в JSON, журнал или временные файлы.

Поиск ограничен 50 000 элементами/3 секундами и 100 результатами; неполный результат обозначается. Дифф ограничивает объём вычислений для сильно различающихся файлов и сохраняет точное содержимое обеих сторон.

## Проверено

Go-тесты `file_preview_test.go` проверяют local/remote текст, UTF-16 и повреждённую кодировку, бинарные файлы, лимит размера, исключения, traversal/каталоги, нечёткое имя, отмену поиска и deployment подпапку. Windows OpenSSH integration в `batch_integration_windows_test.go` проверяет чтение/сравнение через ProxyJump и ProxyCommand и выбор другого сервера без смены active IDs. Frontend-тесты проверяют вставки/удаления/замены и ограничения diff. Browser mock проверяет вкладки, default/другой сервер, Ctrl+Shift+N/Enter и обновление старой remote-вкладки после переключения сервера. Скриншоты: `dist/ui-review/15-file-comparison.png` и `16-file-workspace.png`.

Новая панель проверена браузером и собрана в Windows exe; её ручная проверка в нативном окне на целевом ноутбуке остаётся пользователю по `smoke-test.md`.
