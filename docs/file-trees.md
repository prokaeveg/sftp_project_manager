# Два дерева файлов

Рабочие панели проекта, просмотра файла и сервера имеют скруглённые углы.
Границы между ними можно перетаскивать: при наведении появляется подсветка
и курсор изменения ширины. Каждая боковая секция изменяется независимо;
размеры сохраняются локально между запусками. Разделитель также можно выбрать
клавишей Tab и перемещать стрелками влево/вправо с шагом 10 px.
Цвет свечения верхней панели задаётся в «Настройки → Общие → Цвет проекта»
и сохраняется в поле `color` проекта в JSON. Для старых проектов используется
синий цвет по умолчанию.
Рядом с цветом доступен ползунок «Размер свечения» (25–150%): он меняет
область распространения градиента. Значение хранится в JSON как `glowSize`;
100% сохраняет прежний размер. Изменения применяются после сохранения.

Реализованный пункт этапа 2. Для экономии контекста читать этот файл и `frontend/src/file-tree.ts`, затем затрагиваемый компонент; весь план не нужен.

- Левая панель показывает полный корень выбранного проекта через `ListProjectLocal`, правая — `rootPath` выбранного сервера через `ListRemote`, независимо от активного маппинга. Путь корня каждой панели — `.`, но локальные потомки относительны проекту, удалённые — серверному корню. Локальный корень автоматически читается при открытии/смене проекта; SSH запускается только по команде пользователя. Локальный проект может не иметь серверов: [ide-workspace.md](ide-workspace.md).
- «Обновить» / «Подключиться / обновить» загружает корень. Раскрытие корня также запускает его загрузку. Раскрытие вложенной папки вызывает только `ListLocal(relativePath)` или `ListRemote(relativePath)` для неё; соседние папки не обходятся.
- Сворачивание сохраняет содержимое в памяти. Повторное раскрытие использует кеш, пока пользователь не обновит ветку.
- У загруженной папки есть «Обновить». Успешное обновление заменяет её непосредственных детей и сбрасывает все вложенные кеши/раскрытия. Другие ветки сохраняются. Обновление корня сбрасывает всё дерево этой панели.
- Ошибка/отмена снимает индикатор загрузки и показывает «Повторить загрузку» у соответствующей папки. Если содержимое было загружено раньше, оно сохраняется с явной пометкой о старых данных. Пустая папка имеет отдельное сообщение.
- Деревья независимы. Сохранение проекта и успешное переключение проекта/подключения/маппинга заменяет оба корня и очищает предпросмотр. Кеш не сохраняется на диск. Все действия с backend сериализованы через `work`; настройки и действия дерева блокируются во время операции.
- Исключённые элементы видимы, выбор/раскрытие/передача недоступны. Ссылки не раскрываются и не передаются. Backend повторно проверяет пути и исключения. Файлы и папки можно отмечать независимо в каждой панели; сворачивание сохраняет выбор, обновление очищает выбор панели. Передача использует [общий пакетный план](batch-transfers.md) и полные относительные пути; после передачи назначение обновляется вручную.
- Удалённая навигация использует ленивую SFTP-сессию с самостоятельным жизненным циклом и повторно использует её для дерева и проверок путей одного подключения. Очередь передач сохраняет собственные сессии и блокирует навигацию на время работы. Точный жизненный цикл и состояния описаны в [remote-navigation.md](remote-navigation.md).
- Дерево не наблюдает за изменениями на сервере автоматически; для перечитывания данных используйте «Обновить». Виртуализация больших каталогов не реализована.

## Выделение и контекстное меню

Чекбоксы убраны. Клик по строке файла или папки заменяет выделение; Ctrl добавляет или снимает отдельную строку, Shift выбирает диапазон видимых строк, Ctrl+Shift добавляет диапазон. Enter/пробел выделяют строку с фокусом. Папка раскрывается и сворачивается только отдельной стрелкой. Сворачивание сохраняет выделение вложенных файлов.

ПКМ по выделенной строке сохраняет весь выбор, по другой строке — выбирает её. Меню содержит «Загрузить на <сервер по умолчанию>» и «Скачать с <сервер по умолчанию>». Если серверов несколько, появляются «Загрузить на» и «Скачать с» с выбором сервера. Быстрые кнопки панели также показывают название сервера по умолчанию. Escape, клик снаружи, прокрутка и смена проекта/сервера закрывают меню.

Оба действия используют выделение той панели, где открыто меню. Удалённые пути сначала переводятся в пути проекта через отображающий их маппинг, затем — в путь выбранного сервера через целевой маппинг. Просмотр unmapped-путей разрешён, передача их отклоняется. Весь выбор должен находиться внутри одного маппинга каждого направления; иначе показана ошибка. `PreviewBatchForServer` строит снимок указанного подключения, не меняет активный сервер, настройки или сессию дерева. Перед записью остаются общий предпросмотр и подтверждение очереди.

Код: `file-tree.ts` — состояние, загрузка и перевод project-relative upload в mapping-relative; `components/FileTree.vue` — рекурсивный UI; `App.vue` — две панели, сериализация операций и сброс выбора. `ListProjectLocal` дополняет Go API; прежний `ListLocal` остаётся для совместимости с маппингами.

Автоматическая проверка: `make frontend-test` (или `npm --prefix frontend test`) проверяет ленивую загрузку, кеш, обновление, ошибки/повтор, запрет запросов к исключениям/ссылкам, подавление повторной загрузки, независимость нового корня от старого запроса и множественный выбор. Тесты используют встроенный Node test runner, без новых зависимостей; для запуска `.ts` нужен Node 22.18+ или 24+. Проверка Vue/TypeScript выполняется сборкой. Ручные проверки окна: [smoke-test.md](smoke-test.md).
