# Два дерева файлов

Реализованный пункт этапа 2. Для экономии контекста читать этот файл и `frontend/src/file-tree.ts`, затем затрагиваемый компонент; весь план не нужен.

- Каждая панель показывает корень выбранного маппинга, относительный путь корня — `.`. До команды пользователя каталоги не читаются, SSH не запускается.
- «Обновить» / «Подключиться / обновить» загружает корень. Раскрытие корня также запускает его загрузку. Раскрытие вложенной папки вызывает только `ListLocal(relativePath)` или `ListRemote(relativePath)` для неё; соседние папки не обходятся.
- Сворачивание сохраняет содержимое в памяти. Повторное раскрытие использует кеш, пока пользователь не обновит ветку.
- У загруженной папки есть «Обновить». Успешное обновление заменяет её непосредственных детей и сбрасывает все вложенные кеши/раскрытия. Другие ветки сохраняются. Обновление корня сбрасывает всё дерево этой панели.
- Ошибка/отмена снимает индикатор загрузки и показывает «Повторить загрузку» у соответствующей папки. Если содержимое было загружено раньше, оно сохраняется с явной пометкой о старых данных. Пустая папка имеет отдельное сообщение.
- Деревья независимы. Сохранение проекта и успешное переключение проекта/подключения/маппинга заменяет оба корня и очищает предпросмотр. Кеш не сохраняется на диск. Все действия с backend сериализованы через `work`; настройки и действия дерева блокируются во время операции.
- Исключённые элементы видимы, выбор/раскрытие/передача недоступны. Ссылки не раскрываются и не передаются. Backend повторно проверяет пути и исключения. Файлы и папки можно отмечать независимо в каждой панели; сворачивание сохраняет выбор, обновление очищает выбор панели. Передача использует [общий пакетный план](batch-transfers.md) и полные относительные пути; после передачи назначение обновляется вручную.
- Каждое удалённое чтение пока создаёт отдельную SSH/SFTP-сессию. Переиспользование соединения, наблюдение за изменениями файлов и виртуализация больших каталогов не реализованы.

Код: `file-tree.ts` — состояние и загрузка; `components/FileTree.vue` — рекурсивный UI; `App.vue` — две панели, сериализация операций и сброс выбора. API Go не изменён.

Автоматическая проверка: `make frontend-test` (или `npm --prefix frontend test`) проверяет ленивую загрузку, кеш, обновление, ошибки/повтор, запрет запросов к исключениям/ссылкам, подавление повторной загрузки, независимость нового корня от старого запроса и множественный выбор. Тесты используют встроенный Node test runner, без новых зависимостей; для запуска `.ts` нужен Node 22.18+ или 24+. Проверка Vue/TypeScript выполняется сборкой. Ручные проверки окна: [smoke-test.md](smoke-test.md).
