# Проекты, подключения и маппинги

Краткая навигация для продолжения разработки; не заменяет основной план.

## Контракт

Настройки схемы 2 содержат `projects` и активные `activeProjectID`, `activeConnectionID`, `activeMappingID`.

- Проект: `id`, `name`, абсолютный `localRoot`, `connections`, необязательный `defaultConnectionID`. Проект может существовать без серверов (`connections: []`). Первый созданный сервер становится сервером по умолчанию; его можно изменить в настройках.
- Подключение проекта: `id`, `name`, `connection` с параметрами SSH, `mappings`, необязательный `excludes` (контракт: [exclusions.md](exclusions.md)).
- Маппинг: `id`, относительный `localPath` (например `.` или `src`), абсолютный POSIX `remotePath`.

Пустые ID новых объектов назначает сервис при сохранении; UI может заранее назначить ID новому серверу для выбора default в черновике. `SaveProject` сохраняет весь проект. `SelectProject(projectID, "", "")` выбирает сервер по умолчанию и первый маппинг без SSH; явные ID выбирают конкретный сервер/маппинг. У локального проекта активен только project ID, `Profile` отсутствует. При выбранном сервере `Profile` содержит корни маппинга и снимок SSH-параметров. Старым проектам без default назначается первый сервер в памяти без записи при загрузке.

## Поведение

В [рабочем окне](ide-workspace.md) слева всегда полный локальный проект (`ListProjectLocal`), справа выбранный удалённый маппинг. Локальный корень читается автоматически без SSH; сервер читается только явно. Переключение очищает выбор/предпросмотр и перечитывает локальное дерево. Редактирование проекта/серверов вынесено в модальное окно с отдельным черновиком, который можно сохранить или отменить. Для upload путь полного проекта переводится в выбранный маппинг; путь вне маппинга отклоняется.

Сервис проверяет все подключения и маппинги проекта. Внутри одного подключения запрещены пересекающиеся локальные корни и удалённые корни, включая совпадение и вложенность. На Windows локальные сравнения учитывают нечувствительность к регистру. Между разными подключениями одинаковые пути допустимы. Ссылки/junctions и выход из корня запрещены существующим mapping-кодом.

Конфигурация схемы 1 с одним профилем мигрирует в память; загрузка не перезаписывает исходный файл. При следующем сохранении прежний файл попадает в `settings.json.bak` и дополнительно в `settings.json.v1.bak`, которая сохраняет исходник после следующих сохранений. Удаление папки после сохранения не должно мешать запуску окна; доступ к ней проверяется при операции.

## Навигация и границы

`internal/config` — модель и миграция; `internal/application` — сохранение/выбор/валидация; `app.go` — Wails bridge; `frontend/src/App.vue` — черновик и селекторы. Предпросмотр передачи по-прежнему хранит снимок профиля, а не ссылку на активные ID.

Импорт алиасов и отдельная оценка: [ssh-discovery.md](ssh-discovery.md); исключения: [exclusions.md](exclusions.md); прокси: [proxy-connections.md](proxy-connections.md); рекурсивная передача: [batch-transfers.md](batch-transfers.md). Общая очередь пока ожидается. Проверки фиксируются в `verification.md`, ручные сценарии — в `smoke-test.md`.
